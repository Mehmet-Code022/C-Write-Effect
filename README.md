# C-Write-Effect ⌨️

C++ ile geliştirilmiş, terminal için dinamik ve gerçekçi bir daktilo efekti aracı.

## 🚀 Özellikler
- **Hız Kontrolü:** Her cümle için özel hız tanımlama.
- **Hata Simülasyonu:** Ayarlanabilir oranlarda insansı yazım hataları ve otomatik düzeltme.
- **Renk Desteği:** Kullanıcı ismini otomatik algılama ve mavi renkle vurgulama.
- **Doğal Akış:** Noktalama işaretlerinde gerçekçi duraksamalar.
